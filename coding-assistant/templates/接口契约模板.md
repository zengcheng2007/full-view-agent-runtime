## 通用约定

- Base URL: `https://api.example.com/v1`
- 认证方式: Bearer Token
- 请求格式: `application/json`
- 响应格式: `application/json`
- 字段命名: snake_case
- 分页参数: `page`, `page_size`

## 通用错误码

| HTTP 状态 | 业务码 | 说明 |
|---|---|---|
| 400 | INVALID_PARAM | 参数校验失败 |
| 401 | UNAUTHORIZED | 未认证 |
| 403 | FORBIDDEN | 无权限 |
| 404 | NOT_FOUND | 资源不存在 |
| 500 | INTERNAL_ERROR | 服务器内部错误 |

## 接口清单

### GET /api/users
获取用户列表

**查询参数：**
| 字段 | 类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| page | integer | 否 | 页码 | 1 |
| page_size | integer | 否 | 每页条数 | 20 |

**响应：**
```json
{
  "code": 0,
  "data": {
    "items": [
      {
        "id": "u_001",
        "name": "张三",
        "email": "zhangsan@example.com"
      }
    ],
    "total": 100,
    "page": 1,
    "page_size": 20
  }
}
```

### POST /api/users
创建用户

**请求体：**
| 字段 | 类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| name | string | 是 | 用户名称 | "张三" |
| email | string | 是 | 邮箱 | "zhangsan@example.com" |

**响应：**
```json
{
  "code": 0,
  "data": { "id": "u_001" }
}
```
