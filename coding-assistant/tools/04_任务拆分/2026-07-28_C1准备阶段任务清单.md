# C1 准备阶段任务清单

## 批次 1：worktree 并行

### C1-A：原系统能力矩阵

- 目标：形成可审查的真实能力矩阵，判断出租房两个演示问题的证据状态。
- 可读写：`docs/c1/c1-capability-matrix.md`、`WORKTREE-COMPLETION.md`。
- 可只读：运行时源码、`qxst-sj` 源码、项目方案文档。
- 禁止：所有业务代码、测试、前端、配置、真实运行产物。
- 完成标准：五域证据、当前 Agent 接线状态、出租房两类问题结论、待确认项均写入 `docs/c1/c1-capability-matrix.md`。

### C1-B：生产接线五层测试

- 目标：为已有真实实现的能力建立五层接线正反例测试。
- 可读写：`tests/**`、`WORKTREE-COMPLETION.md`。
- 可只读：`src/full_view_agent/**`、`pyproject.toml`、既有测试。
- 禁止：业务 Adapter/Catalog/QuerySpec 语义变更、前端、真实凭据、运行产物。
- 完成标准：至少一个已有能力的五层正例与逐层拒绝反例；测试快速、离线、确定性。

## 批次 2：待批次 1 合并与审核后创建

- C1-C：出租房纵向切片。只有 C1-A 证明真实接口与口径后才创建；若缺证据，改为“接口核验/业务方待确认”，不得编写假能力。
