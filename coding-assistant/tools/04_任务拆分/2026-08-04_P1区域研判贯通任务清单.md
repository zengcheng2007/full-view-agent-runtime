## 完成标准

- API 只接收受控 AnalysisRequest 或服务端 plan_id，不接收客户端计划正文；
- Plan 必须按 tenant/user/run/request 加载并在当前授权下重新规划；
- 研判步骤只通过 `governance.semantic_query` 执行；
- LangGraph 只负责编排和恢复，Harness/Policy/Result/Evidence 仍是唯一业务门禁；
- 单主题失败可得到结构化 partial，其余主题不被误判为 0；
- 取消、重新认证和 checkpoint 恢复不重复 Tool、Result、Evidence；
- 全量测试、Ruff、Pyright、compileall 通过；
- 未通过真实 HTTP/模型验收的能力不得在生产 Catalog 或文档中宣称可用。

## 禁止项

- 不修改当前运行中的 `p1-integration`；
- 不修改 `.env`、`evals/runs/**`、Dockerfile、模板 Agent/SOP/Prompt；
- 不恢复 Native 新功能开发；
- 不直接合并未经 reviewer 验证的 worktree；
- 不为了通过测试放宽权限、fingerprint 或完成校验。
