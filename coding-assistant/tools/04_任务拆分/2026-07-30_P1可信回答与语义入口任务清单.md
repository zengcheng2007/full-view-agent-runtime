## P1-G：可信回答事实门禁

文件边界：

- 可读写：
  - `src/full_view_agent/application/answer_grounding.py`
  - `src/full_view_agent/application/harness.py`
  - `src/full_view_agent/application/context_builder.py`
  - `src/full_view_agent/evaluation/contracts.py`
  - `src/full_view_agent/evaluation/runner.py`
  - `tests/test_harness.py`
  - `tests/test_context_builder.py`
  - `tests/test_eval_runner.py`
- 其他后端源码只读。
- 禁止修改前端、数据库、凭据、历史 Eval 运行产物和 C1 文档 worktree。

步骤：

1. 测试先行：固定合法原始数值、合计、占比、并列与非法数字反例。
2. 实现事实账本：原始事实与受控派生计算可追溯到 Result。
3. 测试先行：固定区域、对象、无证据判断和重复修订反例。
4. 实现结构化完成决策与稳定原因码；修订一次仍失败时安全结束，不空转。
5. 为 Eval 增加确定性代码 Grader，不使用 LLM Judge 判事实正确性。
6. 定向测试、Ruff、Pyright、全量 pytest；生成 `WORKTREE-COMPLETION.md`。

完成标准：

- 原 v12 错误回答确定性被拒绝；
- Result 中不存在的数字、区域和对象不能通过；
- 合计、最大/最小、并列、全部相同和合法占比可复算；
- Native/LangGraph 共用同一完成决策；
- 不再出现无反馈的 `loop_detected`。

## P1-S：住房与事件统一语义入口

文件边界：

- 可读写：
  - `src/full_view_agent/semantic/action_resolver.py`
  - `src/full_view_agent/semantic/catalog.py`
  - `src/full_view_agent/semantic/compiler.py`
  - `src/full_view_agent/semantic/query_spec.py`
  - `src/full_view_agent/semantic/validator.py`
  - `src/full_view_agent/application/semantic_wiring.py`
  - `tests/test_semantic_action_resolver.py`
  - `tests/test_semantic_catalog.py`
  - `tests/test_semantic_compiler.py`
  - `tests/test_semantic_validator.py`
  - `tests/test_semantic_wiring.py`
- 其他后端源码只读。
- 禁止修改 P1-G 文件、前端、数据库、凭据、Eval 运行产物和部署门禁。

步骤：

1. 测试先行：住房租赁类型、事件当前快照通过统一语义入口解析。
2. 将可执行主题从人口硬编码白名单改为 Catalog/Binding 派生。
3. 住房仅开放区域自身按租赁类型汇总；默认关闭的 `next_area` 不得重新暴露。
4. 事件仅开放区域自身三层办结率快照；不支持时间、阈值、总量和下级区划。
5. 增加未知维度、未知筛选、越权区域和禁用能力反例。
6. 定向测试、Ruff、Pyright、全量 pytest；生成 `WORKTREE-COMPLETION.md`。

完成标准：

- 人口、住房、事件均通过同一 `semantic_query` 入口解析到既有 Canonical Tool；
- 模型面不暴露物理表、列、URL、SQL 或 Adapter；
- Registry、Catalog、Compiler、Policy 和部署门禁保持一致；
- 不含固定地区名、固定问题文本或固定 Tool 顺序；
- 人口既有能力不回退。

## P1-R：审核 Gate

Reviewer 只读，不改源码：

1. 核对两个 worktree 完成报告和文件边界。
2. 审查是否存在固定场景、权限扩大、门禁绕过和无证据回答。
3. Fresh 运行 Ruff、Pyright、全量 pytest。
4. 运行 Native/LangGraph 差分与真实住房查询回归。
5. 输出走查报告；有问题退回对应 Builder 修复，不直接代改。
