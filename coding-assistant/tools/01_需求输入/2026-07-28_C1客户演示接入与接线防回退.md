# C1 客户演示接入与接线防回退

## 需求目标

在不新增任意 SQL、物理表/字段暴露或未验证业务承诺的前提下，为下一步“出租房”客户演示纵向切片建立真实接口证据与生产接线防回退能力。

## 已确认架构约束

- 运行时默认编排为 LangGraph；NativeOrchestrator 冻结。
- 新能力扩展单位是受控 Catalog + QuerySpec + Compiler + Adapter + Policy + Result/Evidence + Eval，不是为每个问法新增固定 Tool。
- 客户演示能力必须来自真实接口、受真实权限约束、包含 Evidence；Mock/脚本测试不可替代生产 HTTP 验收。
- `qxst-sj` 当前存在大范围用户未提交修改，本批次不修改其代码。

## 本批次范围

1. 盘点原系统五个业务域的真实入口、接口、参数、返回字段、区域粒度、权限来源与可安全接入性；
2. 用现有已实现能力建立生产接线五层离线测试：Adapter、Registry、权限、模型可见、HTTP Transport；
3. 给出出租房“区域按租赁类型汇总”和“全市按区县汇总”是否具备真实接入证据的结论。

## 非目标

- 不在本批实现出租房、网格事件、楼栋画像新业务能力；
- 不把接口未证明的分组、统计口径或数据集写成可用能力；
- 不修改前端和真实凭据；
- 不进行真实生产 HTTP 调用。

## 验收标准

- 输出可定位源码证据的能力矩阵；
- 五层接线正例和逐层拒绝反例可离线复现；
- 任务不越过文件边界，完整保留 V3.2 完成报告；
- 通过全量 pytest、Ruff、Pyright 后进入 Codex 走查。
