## 二、目录分层与职责

```
src/
├── main.js / main.ts              # 入口：初始化框架、注册插件、全局适配
├── App.vue / App.tsx              # 根组件
├── api/                           # 服务层：按业务领域拆分
│   ├── request.js/ts              #   基础设施：Axios 实例 + 拦截器（🟡 谨慎修改）
│   ├── home.js                    #   业务接口（🟢 可修改）
│   └── ...
├── views/ 或 pages/               # 视图层：路由组件，与路由 1:1
│   ├── Home.vue/tsx
│   └── ...
├── components/                    # 组件层：全局复用组件
│   └── TabBar.vue
├── router/                        # 路由层：集中式路由表
│   └── index.js/ts
├── store/                         # 状态层：全局共享状态
│   └── index.js/ts
├── utils/                         # 工具层：通用常量/工具函数
│   └── icons.js
└── mock/                          # Mock 层：接口未就绪时的本地模拟
    └── ...
```

> **分层原则**：入口 → 路由 → 状态 → 视图 → 组件 → 服务 → 工具。下层不依赖上层。

## 三、文件边界规则

> Agent 在 SOP-01 阶段自动扫描项目文件，按以下分类填入 `项目信息.md` 的文件边界段。

### 🟢 日常可修改

| 路径 | 说明 |
|------|------|
| `src/views/**` | 页面视图组件 |
| `src/api/*.js`（除 `request.js`）| 业务接口模块 |
| `src/components/**` | 公共组件 |
| `src/store/**` | 状态管理 |
| `src/router/**` | 路由配置 |
| `src/utils/**` | 工具函数/常量 |
| `src/mock/**` | 本地模拟数据 |
| `.env*` | 环境变量 |
| `App.vue` / `App.tsx` | 根组件 |
| `README.md` | 项目说明 |

### 🟡 谨慎修改（需评审）

| 路径 | 说明 |
|------|------|
| `vue.config.js` / `vite.config.ts` | 构建配置 |
| `babel.config.js` | Babel 配置 |
| `package.json` | 依赖与脚本 |
| `public/index.html` | SPA HTML 模板 |
| `src/main.js/ts` | 应用入口 |
| `src/api/request.js/ts` | Axios 实例封装（核心基础设施） |
| `.gitignore` | Git 忽略规则 |

### 🔴 只读 / 禁止修改

| 路径 | 说明 |
|------|------|
| `node_modules/` | 第三方依赖 |
| `package-lock.json` / `yarn.lock` | 依赖锁定文件（自动生成） |
| `.git/` | Git 版本控制元数据 |
| `.idea/` | IDE 项目配置 |

## 四、关键架构模式

> Agent 在 SOP-03 技术方案 / SOP-06 编码阶段参照以下模式。

### 4.1 请求与鉴权

```
axios 实例（baseURL + timeout）
  → 请求拦截：注入 token 头
  → 响应拦截：统一处理 { state, msg, data, code }
    → state=false → Toast 提示 + reject
    → code=401/403 → 清理 token + 跳转登录
  → 辅助方法：postForm（表单）、postFormData（文件上传）
```

### 4.2 环境与代理

```
开发环境：.env.development → devServer.proxy 代理 → 后端
生产环境：.env → 直连后端域名
```

### 4.3 移动端适配（H5）

```
设计稿 375px → 1rem = 37.5px
  构建时：postcss-pxtorem 自动 px → rem
  运行时：setRem() 监听 resize，动态设置 html 字号
```

### 4.4 路由设计

```
hash 模式（#/...） → 静态部署无需后端回退
所有页面路由懒加载 → () => import(...)
路由 meta.title → afterEach 拼接页面标题
```

### 4.5 UI 按需引入（Vue）

```
babel-plugin-import + 显式 Vue.use(Comp)
仅打包用到的组件，控制包体积
```

### 4.6 构建部署

```
publicPath: './' → 产物可作为子目录部署
outputDir + assetsDir 控制输出结构
仅 build 输出静态资源 → 接入静态文件服务器或后端静态目录
```
