# 项目配置

> **首次使用必须填写。** Agent 启动时读取本目录识别项目背景、技术栈和文件边界。

## 填写方式

| 项目类型 | 填写方式 |
|---------|---------|
| **全新项目** | Agent 在 SOP-01 询问用户后自动填写 `项目信息.md` |
| **已有项目** | Agent 在 SOP-01 自动分析工程后补全 `项目信息.md`，人确认 |

## 文件说明

| 文件 | 用途 | 谁填 |
|------|------|------|
| `项目信息.md` | 项目名称、技术栈、文件边界、验收命令 | Agent 填 + 人确认 |
| `前端工程基线.md` | 前端技术栈和目录结构参考（仅供参考，可调整） | 只读参考 |
| `后端工程基线.md` | 后端技术栈和组件版本参考（仅供参考，可调整） | 只读参考 |
