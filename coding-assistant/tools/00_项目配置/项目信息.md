## 关键约束

- LangGraph 是默认编排；不得为新增能力恢复或扩展 NativeOrchestrator。
- 新增能力只能经受控 Catalog、QuerySpec、Compiler、Adapter、Policy、Result/Evidence 和 Eval 纵向接入。
- 模型不得生成物理表名、列名、SQL、ES DSL、Adapter 名称或任意 URL。
- 不得把 Mock、脚本或 Live Eval 成功写成真实生产 HTTP 验收。
- 真实业务接口、统计口径、权限、脱敏或跨数据集结论无法验证时，停止并标记“待验证”。
- 同一失败模式连续三次未消除，停止补丁式修复，回到方案/接口/任务拆分阶段。
