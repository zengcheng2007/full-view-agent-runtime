# 后端工程基线

> **仅供参考，不做强制要求。** 具体项目的技术栈、组件版本、架构选型可根据实际情况调整。
>
> 后端项目的目录结构、文件边界与架构参考。SOP-01 路径 B 分析已有后端项目时，Agent 对照此基线识别工程模式，实际以项目现有代码和团队决策为准。
>
> 适用范围：Spring Boot 3.x + Spring Cloud 微服务架构，Maven 多模块工程。

## 二、目录分层与职责

```
<project-root>/
├── pom.xml                              # [父POM] 统一版本号、依赖管理、模块声明
├── CLAUDE.md                           # AI 编码指引（构建命令、模块说明、命名规则）
├── README.md                           # 项目说明
├── .gitignore                          # Git 排除规则
│
├── <common-module>/                    # 🔧 公共基础设施模块
│   ├── pom.xml
│   └── src/main/java/<base-pkg>/
│       ├── common/                     #   通用常量、枚举
│       ├── beans/                      #   通用 POJO（统一响应体、分页封装）
│       ├── config/                     #   通用自动配置（Druid、MyBatis-Plus、Redis）
│       ├── utils/                      #   通用工具类
│       ├── exception/                  #   全局异常 + 业务异常枚举
│       └── interceptor/               #   通用拦截器（日志、鉴权上下文）
│
├── <business-module>/                  # 🏗️ 业务微服务（可部署单元）
│   ├── pom.xml                         #   模块 POM
│   ├── lib/                            #   本地第三方 JAR（🟡 仅整体替换版本）
│   └── src/
│       ├── main/
│       │   ├── java/<base-pkg>/
│       │   │   ├── <Module>Application.java  # 🟡 启动类
│       │   │   ├── controller/         #   🟢 控制器层：接收请求、参数校验、响应封装
│       │   │   ├── service/            #   🟢 服务接口层
│       │   │   │   └── impl/           #   🟢 服务实现层：业务编排、事务管理
│       │   │   ├── mapper/             #   🟢 MyBatis Mapper 接口（DAO）
│       │   │   ├── entity/             #   🟢 实体类 / POJO / DTO / VO
│       │   │   ├── config/             #   🟡 模块级 Spring 配置（跨域、线程池、序列化）
│       │   │   ├── feign/              #   🟢 Feign 远程调用接口声明
│       │   │   ├── handler/            #   🟢 事件处理器 / 消息监听器
│       │   │   └── utils/              #   🟢 模块内部工具类
│       │   └── resources/
│       │       ├── application.yml     #   🟢 本地配置
│       │       ├── bootstrap.yml       #   🟡 Nacos 引导配置
│       │       └── mapper/             #   🟢 MyBatis XML 映射文件
│       └── test/
│           └── java/                   #   🟢 单元测试 / 集成测试
│   └── target/                         # 🔴 Maven 构建产物（禁止修改）
│
└── <gateway-module>/                   # 🚪 API 网关模块
    └── (结构同 business-module)
        ├── config/                     #   路由规则、跨域、安全过滤器
        └── filter/                     #   自定义 GatewayFilter（鉴权、限流）
```

> **分层原则**：Controller → Service → Mapper → Database。上层依赖下层，下层绝不反向依赖上层。
>
> **模块依赖**：`business-module → common-module`。公共层不依赖任何业务模块。

## 三、文件边界规则

> Agent 在 SOP-01 阶段自动扫描项目文件，按以下分类填入 `项目信息.md` 的文件边界段。

### 🟢 日常可修改

| 路径 | 说明 |
|------|------|
| `src/main/java/**/controller/**` | 控制器层：新增/修改 API 入口 |
| `src/main/java/**/service/**` | 服务接口与实现：核心业务逻辑 |
| `src/main/java/**/handler/**` | 事件处理器 / 消息监听器 |
| `src/main/java/**/mapper/**` | MyBatis Mapper 接口（DAO） |
| `src/main/java/**/entity/**` | 实体类 / POJO / DTO / VO |
| `src/main/java/**/feign/**` | Feign 远程调用接口声明 |
| `src/main/java/**/utils/**`（模块级）| 模块内部工具类 |
| `src/main/resources/mapper/**` | MyBatis XML 映射 SQL |
| `src/main/resources/application.yml` | 本地应用配置 |
| `src/test/java/**` | 单元测试与集成测试 |
| `README.md` | 项目说明 |

### 🟡 谨慎修改（需评审）

| 路径 | 说明 |
|------|------|
| `pom.xml`（根 POM） | 全局版本号、依赖管理、模块列表 |
| `pom.xml`（模块 POM） | 模块依赖与构建插件 |
| `<common-module>/src/main/java/**` | 公共基础设施（影响所有业务模块） |
| `src/main/resources/bootstrap.yml` | 注册/配置中心引导配置 |
| `src/main/java/**/config/**` | Spring 配置类（拦截器、线程池、数据源） |
| `*Application.java` | Spring Boot 启动类（扫描路径、注解声明） |
| `lib/**` | 本地第三方 JAR（仅允许整体替换版本，不可修改 JAR 内部） |
| `.gitignore` | Git 排除规则 |
| `CLAUDE.md` | AI 项目指引 |

### 🔴 只读 / 禁止修改

| 路径 | 说明 |
|------|------|
| `target/` | Maven 构建产物（自动生成，随 `mvn clean` 删除） |
| `.git/` | Git 版本控制元数据 |
| `.idea/` | IDE 项目配置 |
| `*.iml` | IDE 模块文件 |

## 四、关键架构模式

> Agent 在 SOP-03 技术方案 / SOP-06 编码阶段参照以下模式。

### 4.1 分层调用链

```
Controller (@RestController / @Validated)
  → 接收 RequestBody / RequestParam / PathVariable
  → 参数校验（@Valid + JSR-303 注解，或 ValidatorUtils）
  → 调用 Service 接口
  → 返回 ApiResult<T> 或 PageResult<T>

Service（接口 + impl/）
  → 业务逻辑编排（不要泄露 HTTP 细节到 Service 层）
  → @Transactional 标注事务边界
  → 调用 Mapper（MyBatis-Plus BaseMapper 或自定义 SQL）
  → 调用 Feign（跨服务，需兜底 fallback）
  → 组装数据返回 DTO（Controller 层负责 DTO → VO 转换）

Mapper（interface extends BaseMapper<T>）
  → 简单 CRUD：MyBatis-Plus 内置方法（LambdaQueryWrapper）
  → 复杂查询：自定义 XML 映射 SQL
  → 多数据源：@DS 注解切换
```

### 4.2 统一响应体

```java
// common-module 中定义，所有模块复用
public class ApiResult<T> {
    private Integer code;    // 业务状态码（200 成功，其他见枚举）
    private String message;  // 提示信息
    private T data;          // 业务数据

    public static <T> ApiResult<T> ok(T data) { ... }
    public static <T> ApiResult<T> fail(Integer code, String message) { ... }
}

public class PageResult<T> {
    private List<T> records;     // 当前页数据
    private Long total;          // 总记录数
    private Integer pageNum;    // 当前页码
    private Integer pageSize;   // 每页大小
}
```

### 4.3 服务间调用与鉴权

```
外部请求
  → Gateway（路由、鉴权、限流）
    → 认证过滤器：校验 token（JWT / OAuth2）
    → 解析用户信息注入 Header（X-User-Id, X-User-Name, X-Tenant-Id）
    → 路由转发到下游服务
  → Business-Module
    → 拦截器读取 Header 中的用户上下文
    → 写入 ThreadLocal（请求结束清理，防内存泄漏）
    → Feign RequestInterceptor 自动透传上下文到下游
```

### 4.4 配置管理

```
本地配置（application.yml）
  → 仅保留不随环境变化的配置（日志级别、框架开关）

远程配置中心（Nacos / Apollo）
  → 数据库连接、Redis 地址、Feign 超时等环境相关配置
  → shared-configs 拆分：common.properties + <module>.properties
  → @RefreshScope 标记需要热刷新的 Bean（注意：数据源刷新需要特殊处理）
```

### 4.5 异常处理

```
业务异常统一抛出自定义 BusinessException(code, message)
  → 全局异常处理器 @RestControllerAdvice
    → BusinessException → ApiResult.fail(code, message)
    → MethodArgumentNotValidException → 参数校验失败详情
    → Exception → 兜底 log.error + 统一 "系统繁忙"
  → 禁止 catch 后吞异常或返回 null；禁止 e.printStackTrace()
```

### 4.6 日志规范

```
日志分级使用：
  → error：系统错误、第三方调用失败（带上下文参数，方便排查）
  → warn：业务异常、降级触发、重试
  → info：关键业务节点（接口入参出参脱敏后、定时任务执行状态）
  → debug：开发调试（生产关闭）

链路追踪：
  → Micrometer Tracing 自动注入 traceId / spanId
  → Feign / MQ / 异步线程中正确透传
  → 日志 pattern 包含 [%X{traceId:-}] [%X{spanId:-}]
```

### 4.7 数据库访问规约

```
单表操作：MyBatis-Plus LambdaQueryWrapper / LambdaUpdateWrapper（类型安全）
多表关联：自定义 Mapper XML（SQL 写在 resources/mapper/ 下）
分页：MyBatis-Plus Page<T> + PageHelper（二选一，不要混用）

禁止项：
  ✗ Service 层拼接 SQL 字符串
  ✗ 循环内逐条查询数据库（用 batch 或 IN 查询替代）
  ✗ SELECT *（明确列出需要的列）
  ✗ 大事务（事务内不要做 RPC 调用或发 MQ）
```

## 五、探测清单（SOP-01 路径 B）

| 探测目标 | 探测方法 | 写入字段 |

| 服务调用 | 读 `pom.xml`：`spring-cloud-starter-openfeign` | 技术栈-RPC |
| 熔断降级 | 读 `pom.xml`：`sentinel` 或 `resilience4j` | 技术栈-熔断 |

| 认证鉴权 | 读 `pom.xml`：`spring-security` / `cas-client` / `java-jwt` / `oauth2` | 技术栈-认证 |

| 模块列表 | 读根 `pom.xml`：`<modules>` 标签 | 模块结构 |
| 目录分层 | 扫描 `src/main/java/` 下 controller/service/mapper/entity/config/feign 目录 | 目录结构 |
| 公共模块 | 扫描不含 `Application.java` 的独立模块 | 公共模块 |
| 本地 JAR | 扫描 `lib/` 目录 + `pom.xml` 中 `system` scope 依赖 | 第三方依赖 |
| 构建命令 | 读 README/CLAUDE.md 或 `pom.xml` build 插件 | 验收命令 |
