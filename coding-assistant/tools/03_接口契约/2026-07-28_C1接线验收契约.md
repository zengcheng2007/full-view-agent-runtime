# C1 接线验收契约

## 五层通过条件

| 层 | 通过定义 | 反例 |
|---|---|---|
| Adapter | 目标能力有可构造的、受控的 Adapter | Adapter 缺失/构造失败 |
| Registry | 生产 Registry 注册并能按能力 ID 发现 | Registry 未注册 |
| Policy | 已授权主题/数据集可通过，未授权必须拒绝 | 数据集或主题权限缺失 |
| 模型可见性 | 模型得到的可选 Tool 集仅包含授权可见能力 | 被隐藏能力不应泄露给模型 |
| HTTP Transport | 使用可控 transport 时请求路径、认证上下文和受控结果契约正确 | 上游异常应映射为受控失败而非编造回答 |

## 约束

- Stub 只证明运行时的 HTTP 组装与结果处理，不证明原系统生产接口存在；
- 不断言模型的唯一 Tool 调用顺序；
- 不允许测试引入真实 token、物理表/字段或任意 URL。
