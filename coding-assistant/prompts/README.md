# Prompt 库说明

> Prompt 库是 Agent 内部调用的工具箱，不是研发要手动执行的流程。

---

## 使用原则

研发只按 10 个阶段推进。Agent 会根据当前阶段自动引用本目录下的 Prompt。除非调试或二次开发，用户不需要手动选择 Prompt。

---

## Prompt 分层

### 主流程自动调用

| Prompt | 用途 | 触发阶段 |
|---|---|---|
| `P-C-1-需求理解.md` | 分析需求、列出不确定点 | SOP-02 需求吃透 |
| `P-C-2-技术方案生成.md` | 生成技术方案（数据流/接口/决策/风险）| SOP-03 技术方案 |
| `P-C-3-接口契约生成.md` | 生成 api.md 或 OpenAPI 契约 | SOP-04 接口对齐 |
| `P-C-4-测试补充.md` | 补充单元测试（正向/反向/边界/异常）| SOP-07 自测 |
| `P-C-5-任务拆分.md` | 按业务闭环拆分编码任务 | SOP-05 任务拆分 |
| `P-C-6-代码走查.md` | 样式规范/契约对照/自欺欺人检查 | SOP-08 走查 |
| `P-C-7-联调调试.md` | 四阶段系统调试 | SOP-09 联调 |
| `P-C-8-资产沉淀.md` | 提炼可复用组件/Prompt/规则 | SOP-10 沉淀 |

### 事件触发调用

| Prompt | 触发条件 |
|---|---|
| `P-C-9-技术复盘.md` | 编码完成/上线后，需要复盘总结 |

### 场景专用调用

| Prompt | 触发条件 | 适用场景 |
|---|---|---|
| `P-C-B-设计稿读取确认.md` | 进入 SOP-06 编码前，确认设计稿数据源(MCP 直读 / 截图参照) | **A-前端(从0到1 · 前端)** |

---

## 设计边界

- Prompt 是 Agent 的内部动作，不增加用户操作步骤。
- SOP 是用户可感知流程，Prompt 是 Agent 执行细节。
- 新增 Prompt 前，先判断是否能归入现有 10 个阶段。
