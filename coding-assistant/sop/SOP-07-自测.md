# SOP-07 · 自测

## 目标
编码完成后执行完整测试验证：单元测试 + 关键路径手测 + 跨浏览器（前端）。

---

## 前置条件
- SOP-06 编码完成，所有 Step commit 已提交

---

## 输入

> Agent 执行本阶段前，必须先验证以下文件是否存在。
> **输入缺失时，不可直接终止流程。**

| # | 读取路径 | 用途 | 适用场景 | 来源阶段 |
|---|---------|------|---------|---------|
| 1 | `coding-assistant/tools/05_编码产物/编码索引-[日期].md` | 改动文件清单、Step 完成情况 | A, C, D, E | SOP-06 |
| 2 | `coding-assistant/tools/04_任务拆分/任务清单-[日期].md` | 每步完成标准（用于验证） | A, C, D, E | SOP-05 |

**输入缺失处理：** 任一文件不存在时，Agent 使用 `AskUserQuestion`：

```
问题: [编码索引 / 任务清单] 未就绪，无法直接执行自测，如何处理？
  [A] 回到上一阶段补充 — 完成前置产出后继续
  [B] 对话引导 — 我现在描述改动范围和验收标准，Agent 直接跑测试并生成报告（标记为"对话生成"）
```

用户选择 [B] 时，Agent 通过对话确认改动文件范围和核心验收标准，直接执行测试命令并生成自测报告，标注"对话生成，待确认"。

---

## 自测清单

- [ ] 单元测试全绿（**不接受"上次跑过"**）
- [ ] 关键路径手测一遍（含异常路径）
- [ ] 跨浏览器（前端）/ 接口冒烟（后端）
- [ ] 边界值（空 / 0 / 极大 / 特殊字符）

---

## 执行步骤

1. 跑全套单元测试：`npm test`（贴输出）
2. 有缺失测试的代码段，套用 `coding-assistant/prompts/P-C-4-测试补充.md` 补测试
3. 测试覆盖：正向 + 反向 + 边界值 + 异常路径
4. 生成 `coding-assistant/tools/06_自测报告/自测报告-[日期].md`（参照 `coding-assistant/templates/自测报告模板.md`）
5. 列出关键路径手测步骤，让用户执行手测
6. 用户手测完成后，汇总结果

---

## 质量要求

- 异常路径必测——不能只测 happy path
- 边界值：空字符串 / 0 / undefined / null / 特殊字符
- 不允许 mock 业务核心逻辑
- 前端：跨浏览器至少 Chrome + Firefox

---
